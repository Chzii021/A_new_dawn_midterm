# ห้องบอส — ฉากแยกสำหรับทดสอบ

เปิด `res://boss_room/boss_room.tscn` แล้วกด F6 (Run Current Scene)
เดินด้วย WASD และโจมตีด้วยคลิกซ้าย/F ตามระบบผู้เล่นเดิม

มีลานหิน 576 × 352, กำแพงและเสาที่ชนได้, กล้องพอดีห้อง,
PlayerSpawn, BossSpawn, ประตูทางใต้ และพื้นที่เริ่มต่อสู้
งานนี้ยังไม่มีตัวบอส/AI และยังไม่เชื่อมทางเข้าจากแผนที่หลักหรือเควส
ภาพห้องวาดจาก `room_art.gd` และแสดงใน editor ได้ สามารถเปลี่ยนเป็น TileMapLayer ภายหลัง

## เชื่อมบอสในภายหลัง

เลือก BossRoom แล้วใส่ PackedScene ของบอสในช่อง Boss Scene
รากฉากบอสต้องเป็น Node2D (เช่น CharacterBody2D)
เดินเข้าลานจะสร้างบอสที่ BossSpawn และปิดประตู
บอสควรส่ง `signal defeated` แบบไม่มี argument เมื่อแพ้
ห้องจะเชื่อมสัญญาณนี้กับ `finish_battle()` เพื่อเปิดประตูอัตโนมัติ
ถ้าบอสใช้สัญญาณอื่น ให้เชื่อมกับ `finish_battle()` เอง
ไม่มี Boss Scene จะเป็นโหมดเดินดูห้องและไม่ล็อกประตู

## เชื่อมทางออก

ใส่เส้นทางฉากใน Return Scene แล้วเดินไปประตูด้านใต้และกด Space
ช่องว่างจะยังไม่เปลี่ยนฉาก มีข้อความแจ้งแทน
เมื่อใช้ `world.tscn` หรือ `village.tscn` ฉากปลายทางจะจัดการจุดเกิดตามโค้ดเดิมของมัน
ยังไม่มีระบบบันทึกตำแหน่งกลับเฉพาะประตูบอส

สัญญาณสำหรับต่อระบบ: `battle_started(boss)`, `battle_finished`, `exit_requested`
ไม่มีการอ่านหรือเขียนสถานะเควส และไม่ได้เปลี่ยน project.godot, player, NPC หรือแผนที่เดิม
ตัวละครในห้องยังใช้ HP/กระเป๋าร่วมผ่านระบบเดิมของโปรเจกต์
