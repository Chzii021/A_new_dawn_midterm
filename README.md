## คำอธิบายโครงการ

เกม **"ฮอดมื้อใหม่ (A New Dawn)"** เป็นเกม 2D Platformer ที่ตีความพื้นบ้านนภาคอีสานไทยใหม่ในมุมของมารดา  
ผู้เล่นเป็นแม่ของไอ้ทอง เดินทางนำกล่องข้าวไปส่งลูก ต้องหลบศัตรู กับดัก และเก็บกระติ๊บข้าวผ่าน 4 ด่าน
